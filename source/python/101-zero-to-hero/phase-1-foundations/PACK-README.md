# Python 101, Phase 1: Foundations

Source pack for lessons 01 to 04 of **Python 101 (Zero to Hero)**. The pack is optional: each lesson shows the code and exercise.
Find these files in https://github.com/Uee03/Code101 under `source/python/101-zero-to-hero/phase-1-foundations/`.
Choose **Code > Download ZIP** at the repository, or use `git clone https://github.com/Uee03/Code101.git`.
The [glossary](https://github.com/Uee03/Code101/blob/main/tutorials/python/GLOSSARY.md) defines the course terms.

| Folder | Lesson | You build | First-timer time |
|--------|--------|-----------|------------------|
| `01-hello-python` | Hello, Python | your first program, and a recipe card | 60 min (two sittings) |
| `02-variables-and-types` | Variables and types | a program that remembers and updates facts | 35 min |
| `03-input-and-math` | Input and math | a tip calculator, and a bill splitter | 35 min |
| `04-making-decisions` | Making decisions | a ticket machine, and a grade checker | 40 min |

## Inside each lesson folder

| Folder or file | What it is |
|----------------|------------|
| `code/` | The finished program from the lesson. Type it yourself first; open this to compare. |
| `exercise/starter/` | Where the "Try it" exercise starts (has `TODO` markers). |
| `exercise/solution/` | The exercise answer. Try before you look. |

## How to run any program

1. Install Python 3.12 or newer (lesson 01).
2. Unzip this pack: Windows, right-click the zip and choose **Extract All**; macOS, double-click it; Linux, `unzip <file>.zip`.
3. Open a terminal **inside** the folder that holds the file (type `cd` followed by the folder path).
4. Run `python <file>.py` (macOS and Linux: `python3 <file>.py`).

For an exercise, copy its named `.py` file from `exercise/starter` into your own `lesson01`, `lesson02`,
`lesson03` or `lesson04` folder, exactly as its lesson says, then run from that folder.
Lesson 01 has a break before Step 7; setup and first coding can be separate sittings.

Example:

```bash
cd 02-variables-and-types/code
python variables.py
```
