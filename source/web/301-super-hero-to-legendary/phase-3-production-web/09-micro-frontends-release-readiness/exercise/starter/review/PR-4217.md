# Pull request 4217: Ship Board v2 as a remote (release 2026.12.0)

Author: team-boards. Planned release: Friday, 16:30 local time.

## What changes
- Board v2 is a new micro-frontend. The shell loads it at runtime from `https://boards.example.test/remote.js`.
- It replaces the existing board page. The old board code is deleted in this pull request.
- Migration 0042 drops the column `tasks.legacy_position` and renames `tasks.position` to `tasks.sort_key`. There is no down migration.
- The REST response for `GET /v1/projects/{id}/tasks` renames `position` to `sortKey`. Mobile clients are told "next sprint".

## Rollout
- The feature flag `board-v2` is set to 100 percent at release time. There is no canary: "we tested it on staging".
- Rollback plan: "redeploy the previous commit".

## Change to the shell
```diff
-const remote = await import(url);
+const remote = await import(/* @vite-ignore */ url);
+remote.mount(element, { token: window.__ACCESS_TOKEN__ });
```
There is no `try`/`catch` and no timeout: "the remote is ours, it will not fail".

## Change to the Content-Security-Policy
```diff
-script-src 'nonce-{nonce}' 'strict-dynamic'
+script-src 'nonce-{nonce}' 'strict-dynamic' 'unsafe-inline' https://boards.example.test
```
Reason given: "the remote's bootstrap code is inline".
