# 05. Build, run and ship

## Why it matters
A debug APK is not a store release. Release URLs, signing keys, cleartext policy and cleanup are separate responsibilities. Make each explicit before handing a package to someone else.

## What you will build
A debug APK, an R8-optimized release AAB, an HTTPS guard, external upload signing and a manual run guide for Python, ASP.NET and Go. Requirements: M-24 and M-25. This chapter does not upload anything or create production credentials.

**Execution status: written (not run).** The user stopped builds/smoke verification during authoring. Earlier captured diagnostics are labelled historical below; they do not verify this final snapshot. Commands here are instructions for a later session, not a claim they were run.

## Before you start
- Android Studio with its bundled JBR; SDK Platform 37.2 (`platforms/android-37.2`), build-tools 36.0.0, accepted SDK licenses; Python 3.10+ for standard-library helpers. No global Gradle is needed. The author machine has JDK 25; app bytecode targets Java 17.
- Studio Settings, Languages & Frameworks, Android SDK: enable Show Package Details and install the platform matching `android-37.2`; SDK Tools needs build-tools 36.0.0 and Platform-Tools. An emulator/browser is for later manual work only, not compilation.
- Read [the design](../../TDD.md), [platform TDD section 12.1](../../../platform/TDD.md) and [version evidence](../../VERSIONS.md). Complete one supported backend separately; do not start infrastructure merely to compile Android.
- Extract `mobile-kotlin-phase-5-ship.zip`: Windows right-click, Extract All; macOS double-click; Linux `unzip mobile-kotlin-phase-5-ship.zip`. Open `05-build-run-ship/code` in Android Studio, not its parent. In the Project pane use Project view to see root files. Save with Ctrl+S (Cmd+S on macOS); a dot on a tab means unsaved.
- All remaining commands run from that code folder unless explicitly stated. `Get-Location` on Windows or `pwd` on Unix should end in `05-build-run-ship/code`. The Windows commands are PowerShell 5.1 compatible. Do not type a PS> or $ prompt prefix. Reopen terminals after changing PATH.

### Step 2. Know what is generated and how to regenerate it

For wrapper recovery only, save your app location, download the official binary archive into a separate bootstrap folder, compare SHA-256 with its official .sha256 response, then extract it. The download does not contain any application data.

**Command (Windows; start in code, later recovery only):**
```powershell
$app = (Get-Location).Path
New-Item -ItemType Directory -Force "$HOME\gradle-bootstrap\wrapper-bootstrap" | Out-Null
Set-Location "$HOME\gradle-bootstrap"
python -c "import urllib.request; urllib.request.urlretrieve('https://services.gradle.org/distributions/gradle-9.6.0-bin.zip','gradle-9.6.0-bin.zip')"
python -c "import hashlib,urllib.request; from pathlib import Path; expected=urllib.request.urlopen('https://services.gradle.org/distributions/gradle-9.6.0-bin.zip.sha256').read().decode().strip(); assert hashlib.sha256(Path('gradle-9.6.0-bin.zip').read_bytes()).hexdigest()==expected"
Expand-Archive gradle-9.6.0-bin.zip -DestinationPath . -Force
```
Now create wrapper-bootstrap/settings.gradle.kts with the complete content below. This is a temporary bootstrap file, not a second Android module.

**File: `wrapper-bootstrap/settings.gradle.kts` (temporary recovery project)**

**Command (Windows; still in the bootstrap containing folder):**

import javax.inject.Singleton

@Singleton
class AuthStateManager @Inject constructor(
    @ApplicationContext context: Context, private val vault: TokenVault
) : Session {
    private val mutableAccount = MutableStateFlow<String?>(null)
    override val accountId = mutableAccount.asStateFlow()
    private fun subject(current: AuthState?): String? = runCatching {
        val payload = current?.idToken?.split('.')?.get(1) ?: return@runCatching null
        org.json.JSONObject(String(android.util.Base64.decode(payload, android.util.Base64.URL_SAFE), Charsets.UTF_8)).getString("sub")
    }.getOrNull()
    private val mutex = Mutex()
    private var state: AuthState? = null
    private val mutableStatus = MutableStateFlow(SessionStatus.Checking)
    override val status = mutableStatus.asStateFlow()
    private val connections = ConnectionBuilder { uri ->
        val url = uri.toString().toHttpUrl()
        HttpUrlPolicy.requireAllowed(url)
        (url.toUrl().openConnection() as HttpURLConnection).apply {
            connectTimeout = 15000; readTimeout = 15000; instanceFollowRedirects = false
        }
    }
    private val configuration = AppAuthConfiguration.Builder().apply {
        if (BuildConfig.DEBUG) setSkipIssuerHttpsCheck(true)
        setConnectionBuilder(connections)
    }.build()
    private val service = AuthorizationService(context, configuration)

    suspend fun restore() = withContext(Dispatchers.IO) {
        mutex.withLock {
            state = try { vault.read()?.let(AuthState::jsonDeserialize) } catch (_: Exception) { null }
            mutableAccount.value = subject(state)
            mutableStatus.value = if (state?.isAuthorized == true && mutableAccount.value != null) SessionStatus.SignedIn else SessionStatus.SignedOut
        }
    }
    private suspend fun discovery(): AuthorizationServiceConfiguration = suspendCancellableCoroutine { continuation ->
        AuthorizationServiceConfiguration.fetchFromUrl(
            Uri.parse(AuthConfig.issuer + "/.well-known/openid-configuration"),
            { config, error ->
                if (config != null) continuation.resume(config)
                else continuation.resumeWithException(IOException("Discovery unavailable", error))
            }, connections)
    }
    suspend fun loginIntent(): Intent {
        val config = discovery()
        require(config.authorizationEndpoint.toString().startsWith(AuthConfig.issuer + "/"))
        val request = AuthorizationRequest.Builder(config, AuthConfig.clientId,
            ResponseTypeValues.CODE, Uri.parse(AuthConfig.redirect))
            .setScope(AuthConfig.scopes).build()
        return service.getAuthorizationRequestIntent(request)
    }
    suspend fun acceptLogin(data: Intent) = withContext(Dispatchers.IO + NonCancellable) {
        val error = AuthorizationException.fromIntent(data)
        if (error?.code == AuthorizationException.GeneralErrors.USER_CANCELED_AUTH_FLOW.code) return@withContext
        if (error != null) throw IOException("Authorization failed")
        val response = AuthorizationResponse.fromIntent(data) ?: return@withContext
        mutex.withLock {
            val next = AuthState(response, null)
            val token = tokenRequest(response.createTokenExchangeRequest())
            next.update(token, null)
            vault.save(next.jsonSerializeString())
            state = next
            mutableAccount.value = subject(next)
            mutableStatus.value = SessionStatus.SignedIn
        }
    }
    private suspend fun tokenRequest(request: TokenRequest): TokenResponse = suspendCancellableCoroutine { continuation ->
        service.performTokenRequest(request) { token, error ->
            if (token != null) continuation.resume(token)
            else continuation.resumeWithException(IOException("Session needs sign-in", error))
        }
    }
    override suspend fun accessToken(force: Boolean, rejected: String?): String =
        withContext(Dispatchers.IO + NonCancellable) {
            mutex.withLock {
                val current = state ?: throw IOException("Sign in required")
                val existing = current.accessToken
                val expires = current.accessTokenExpirationTime ?: 0L
                if (existing != null && expires - System.currentTimeMillis() > 60000L &&
                    (!force || (rejected != null && rejected != existing))) return@withLock existing
                try {
                    val token = tokenRequest(current.createTokenRefreshRequest())
                    current.update(token, null)
                    vault.save(current.jsonSerializeString())
                    current.accessToken ?: throw IOException("Sign in required")
                } catch (_: Exception) {
                    mutableStatus.value = SessionStatus.SignedOut
                    throw IOException("Sign in required")
                }
            }
        }
    suspend fun logoutIntent(): Intent? {
        val current = state ?: return null
        val config = current.authorizationServiceConfiguration ?: return null
        if (config.endSessionEndpoint == null) return null
        return service.getEndSessionRequestIntent(EndSessionRequest.Builder(config)
            .setIdTokenHint(current.idToken).setPostLogoutRedirectUri(Uri.parse(AuthConfig.logout)).build())
    }
    suspend fun clear() = mutex.withLock {
        vault.clear(); state = null; mutableAccount.value = null; mutableStatus.value = SessionStatus.SignedOut
    }
}

package com.code101.tasks.data.auth

import android.content.Context
import android.security.keystore.KeyGenParameterSpec
import android.security.keystore.KeyProperties
import android.util.Base64
import androidx.datastore.preferences.core.edit
import androidx.datastore.preferences.core.stringPreferencesKey
import androidx.datastore.preferences.preferencesDataStore
import dagger.hilt.android.qualifiers.ApplicationContext
import kotlinx.coroutines.flow.first
import java.security.KeyStore
import javax.crypto.Cipher
import javax.crypto.KeyGenerator
import javax.crypto.SecretKey
import javax.crypto.spec.GCMParameterSpec
import javax.inject.Inject
import javax.inject.Singleton

private val Context.authStore by preferencesDataStore("auth")

@Singleton
class TokenVault @Inject constructor(@ApplicationContext private val context: Context) {
    private val blob = stringPreferencesKey("ciphertext")
    private fun key(): SecretKey {
        val store = KeyStore.getInstance("AndroidKeyStore").apply { load(null) }
        (store.getKey("tasks_auth_key", null) as? SecretKey)?.let { return it }
        return KeyGenerator.getInstance(KeyProperties.KEY_ALGORITHM_AES, "AndroidKeyStore").apply {
            init(KeyGenParameterSpec.Builder("tasks_auth_key", KeyProperties.PURPOSE_ENCRYPT or KeyProperties.PURPOSE_DECRYPT)
                .setBlockModes(KeyProperties.BLOCK_MODE_GCM)
                .setEncryptionPaddings(KeyProperties.ENCRYPTION_PADDING_NONE)
                .setKeySize(256).build())
        }.generateKey()
    }
    suspend fun save(json: String) {
        val cipher = Cipher.getInstance("AES/GCM/NoPadding")
        cipher.init(Cipher.ENCRYPT_MODE, key())
        val bytes = cipher.iv + cipher.doFinal(json.toByteArray(Charsets.UTF_8))
        context.authStore.edit { it[blob] = Base64.encodeToString(bytes, Base64.NO_WRAP) }
    }
    suspend fun read(): String? {
        val encoded = context.authStore.data.first()[blob] ?: return null
        val bytes = Base64.decode(encoded, Base64.NO_WRAP)
        require(bytes.size > 28)
        val cipher = Cipher.getInstance("AES/GCM/NoPadding")
        cipher.init(Cipher.DECRYPT_MODE, key(), GCMParameterSpec(128, bytes.copyOfRange(0, 12)))
        return cipher.doFinal(bytes.copyOfRange(12, bytes.size)).toString(Charsets.UTF_8)
    }
    suspend fun clear() { context.authStore.edit { it.remove(blob) } }
}

import okhttp3.Interceptor
import okhttp3.Response
import java.io.IOException
import java.time.ZonedDateTime
import java.time.format.DateTimeFormatter
import java.util.concurrent.atomic.AtomicLong

class RetryGate : Interceptor {
    private val notBefore = AtomicLong(0)
    override fun intercept(chain: Interceptor.Chain): Response {
        while (System.currentTimeMillis() < notBefore.get()) {
            if (chain.call().isCanceled()) throw IOException("Canceled")
            try { Thread.sleep(minOf(100L, notBefore.get() - System.currentTimeMillis()).coerceAtLeast(1)) }
            catch (_: InterruptedException) { Thread.currentThread().interrupt(); throw IOException("Canceled") }
        }
        return chain.proceed(chain.request()).also { response ->
            if (response.code == 429 || response.code == 503) {
                val header = response.header("Retry-After")
                val until = header?.toLongOrNull()?.let { System.currentTimeMillis() + it * 1000 }
                    ?: runCatching { ZonedDateTime.parse(header, DateTimeFormatter.RFC_1123_DATE_TIME).toInstant().toEpochMilli() }.getOrDefault(0)
                notBefore.updateAndGet { previous -> maxOf(previous, until) }
            }
        }
    }
}

class TasksRepositoryImpl @Inject constructor(private val remote: Remote, private val store: CacheStore,
    private val settings: BackendSettings, network: NetworkMonitor, private val session: Session) : TasksRepository {
    override val snapshot = combine(store.snapshot, session.accountId) { cache, id ->
        if (id == null || (cache.me != null && cache.me.id != id)) Snapshot() else cache
    }.stateIn(CoroutineScope(SupervisorJob() + Dispatchers.IO), SharingStarted.Eagerly, Snapshot())

    override suspend fun teams(q: String) {

        if (current().me?.id?.let { it != me.id } == true) {
            throw ApiFailure(ApiProblem("account-changed", "Delete offline data before switching accounts", 409))
        }
        val result = remote.teams(q)
        change { it.copy(teams = if (q.isEmpty()) result else (it.teams + result).distinctBy { t -> t.id }, me = me) }
    }
    override suspend fun projects(teamId: String, archived: Boolean) {
        ensureMe()
        val result = remote.projects(teamId, archived)
        change { it.copy(projects = it.projects.filterNot { p -> p.teamId == teamId && p.archived == archived } + result) }
    }
    override suspend fun tasks(projectId: String, statuses: Set<String>, sort: String, more: Boolean) {
        ensureMe()
        val query = statuses to sort
        val append = more && queries[projectId] == query
        if (append && cursors[projectId] == null) return
        val result = try { remote.tasks(projectId, statuses, sort, if (append) cursors[projectId] else null) }
        catch (failure: ApiFailure) {
            if (append && failure.problem.status == 400) { cursors.remove(projectId); return tasks(projectId, statuses, sort, false) }
            throw failure
        }
        queries[projectId] = query; cursors[projectId] = result.nextCursor
        change { s ->
            val keep = s.tasks.filter { it.syncState != "synced" || it.projectId != projectId || append }
            s.copy(tasks = (keep + result.items.filter { server -> keep.none { it.id == server.id && it.syncState != "synced" } })
                .associateBy { it.id }.values.toList())
        }
    }
    override suspend fun detail(taskId: String) {
        ensureMe()
        if (current().tasks.any { it.id == taskId && it.syncState != "synced" }) return
        val task = remote.task(taskId); val comments = remote.comments(taskId)
        change { s -> s.copy(tasks = s.tasks.filterNot { it.id == taskId } + task,
            comments = s.comments.filter { it.taskId != taskId || it.syncState != "synced" } + comments) }

    private fun fields(draft: TaskDraft) = linkedMapOf("title" to draft.title.trim(), "description" to draft.description,
        "status" to draft.status, "priority" to draft.priority, "assigneeId" to draft.assigneeId?.ifBlank { null },

        if (draft.title.trim().length !in 1..200) errors += FieldError("/title", "title_limit")
        if (draft.description.length > 10000) errors += FieldError("/description", "description_limit")
        if (!draft.dueDate.isNullOrBlank() && runCatching { LocalDate.parse(draft.dueDate) }.isFailure)
            errors += FieldError("/dueDate", "date_format")
        if (!draft.assigneeId.isNullOrBlank() && runCatching { UUID.fromString(draft.assigneeId) }.isFailure)
            errors += FieldError("/assigneeId", "uuid_format")
        if (errors.isNotEmpty()) throw ApiFailure(ApiProblem("validation-error", "", 422, errors))
    }

        ensureMe()
        validate(draft)
        val now = Instant.now().toString()

            if (s.outbox.any { it.id == key }) return@change s
            val taskId = id ?: key
            val source = original ?: s.tasks.find { it.id == taskId }
            val target = source?.copy(title = draft.title.trim(), description = draft.description, status = draft.status,

                s.me?.id.orEmpty(), 0, now, now, "pending")

            if (payload.isEmpty()) return@change s
            val writes = if (create != null) s.outbox.map { if (it.id == create.id) it.copy(payload = payload,

                    if (source == null) "create_task" else "update_task", taskId, projectId, payload, source?.version)
            s.copy(tasks = s.tasks.filterNot { it.id == taskId } + target, outbox = writes)
        }
    }

            val task = s.tasks.first { it.id == taskId }
            val write = PendingWrite(UUID.randomUUID().toString(), (s.outbox.maxOfOrNull { it.seq } ?: 0) + 1,

                outbox = s.outbox + write)
        }
    }

        }
    }

    override suspend fun backend(kind: Backend, custom: String) = drain.withLock {
        backendGuard.withLock {
            check(current().outbox.isEmpty())
            settings.set(if (kind == Backend.Custom) custom else BuildConfig.API_BASE_URL, kind)
            store.change { Snapshot() }; cursors.clear(); queries.clear()
        }
    }
    override suspend fun hasPending(): Boolean = current().outbox.any { it.state == "pending" }
    override suspend fun sync() = drain.withLock {
        change { s -> s.copy(outbox = s.outbox.map { if (it.state == "in_flight") it.copy(state = "pending", attempts = maxOf(1, it.attempts)) else it }) }
        while (true) {
            val rows = current().outbox.sortedBy { it.seq }
            val write = rows.firstOrNull { w -> w.state == "pending" && w.nextAttemptAt <= System.currentTimeMillis() &&
                rows.none { it.seq < w.seq && (it.entityId == w.entityId || it.entityId == w.parentId) } } ?: break
            change { s -> s.copy(outbox = s.outbox.map { if (it.id == write.id) it.copy(state = "in_flight", attempts = maxOf(1, it.attempts)) else it }) }
            try {
                when (write.kind) {
                    "create_task", "update_task", "complete_task" -> {
                        val task = when (write.kind) {
                            "create_task" -> remote.create(write)
                            "update_task" -> remote.edit(write)
                            else -> remote.complete(write)
                        }
                        change { s ->
                            val rest = s.outbox.filterNot { it.id == write.id }.map {
                                it.copy(entityId = if (it.entityId == write.entityId) task.id else it.entityId,
                                    parentId = if (it.parentId == write.entityId) task.id else it.parentId,
                                    baseVersion = if (it.entityId == write.entityId) task.version else it.baseVersion)
                            }
                            val dirty = rest.any { it.entityId == task.id }
                            val local = s.tasks.find { it.id == write.entityId }
                            val result = if (dirty && local != null) local.copy(id = task.id, version = task.version) else task
                            s.copy(tasks = s.tasks.filterNot { it.id == write.entityId } + result,
                                comments = s.comments.map { if (it.taskId == write.entityId) it.copy(taskId = task.id) else it }, outbox = rest)
                        }
                    }
                    "create_comment" -> {
                        val comment = remote.comment(write)
                        change { s -> s.copy(comments = s.comments.filterNot { it.id == write.entityId } + comment,
                            outbox = s.outbox.filterNot { it.id == write.id }) }
                    }
                }
            } catch (failure: Exception) {
                val problem = (failure as? ApiFailure)?.problem
                if (problem?.status == 412) {
                    val server = runCatching { remote.task(write.entityId) }.getOrNull()
                    change { s -> s.copy(tasks = s.tasks.map { if (it.id == write.entityId) it.copy(syncState = "conflict", server = server) else it },
                        outbox = s.outbox.map { if (it.id == write.id) it.copy(state = "conflict", problem = problem) else it }) }
                } else {
                    val retry = failure is IOException || problem?.status in listOf(408, 425, 429) || (problem?.status ?: 0) >= 500
                    val delay = min(3600000L, 1000L * (1L shl min(write.attempts, 12))) + Random.nextLong(1000L)
                    change { s -> s.copy(outbox = s.outbox.map { if (it.id == write.id) it.copy(
                        state = if (retry) "pending" else "failed", attempts = it.attempts + 1,
                        nextAttemptAt = maxOf(System.currentTimeMillis() + delay, problem?.retryAt ?: 0), problem = problem) else it },
                        tasks = s.tasks.map { if (!retry && it.id == write.entityId) it.copy(syncState = "failed") else it },
                        comments = s.comments.map { if (!retry && it.id == write.entityId) it.copy(syncState = "failed") else it }) }
                }
                if (failure is IOException) break
            }
        }
    }
    override suspend fun retry(id: String) {
        val write = current().outbox.find { it.id == id } ?: return
        if (write.state == "conflict") return
        if ((write.problem?.retryAt ?: 0) > System.currentTimeMillis()) return
        change { s -> s.copy(outbox = s.outbox.map { if (it.id == id) it.copy(state = "pending", nextAttemptAt = 0, problem = null) else it }) }
        sync()
    }
    override suspend fun discard(id: String) {
        change { s ->
            val write = s.outbox.find { it.id == id } ?: return@change s
            val dependent = s.outbox.filter { it.entityId == write.entityId || it.parentId == write.entityId }.map { it.id }.toSet()
            s.copy(outbox = s.outbox.filterNot { it.id in dependent },
                tasks = s.tasks.filterNot { it.id == write.entityId && write.kind == "create_task" }
                    .map { if (it.id == write.entityId) it.server ?: it.copy(syncState = "synced") else it },
                comments = s.comments.filterNot { it.id == write.entityId || (write.kind == "create_task" && it.taskId == write.entityId) })
        }
    }
    override suspend fun resolve(taskId: String, keep: Set<String>) {
        val task = current().tasks.first { it.id == taskId }
        val server = task.server ?: remote.task(taskId)
        change { s ->
            val conflict = s.outbox.first { it.entityId == taskId && it.state == "conflict" }
            val payload = conflict.payload.filterKeys { it in keep }
            val local = if (payload.isEmpty()) server else server.copy(
                title = payload["title"] ?: server.title, description = payload["description"] ?: server.description,
                status = payload["status"] ?: server.status, priority = payload["priority"] ?: server.priority,
                assigneeId = if (payload.containsKey("assigneeId")) payload["assigneeId"] else server.assigneeId,
                dueDate = if (payload.containsKey("dueDate")) payload["dueDate"] else server.dueDate,
                syncState = "pending", server = server)
            s.copy(tasks = s.tasks.filterNot { it.id == taskId } + local,
                outbox = s.outbox.filterNot { it.id == conflict.id } +
                    if (payload.isEmpty()) emptyList() else listOf(conflict.copy(payload = payload,
                        baseVersion = server.version, state = "pending", problem = null, nextAttemptAt = 0)))
        }
        sync()
    }
    override suspend fun clear() { drain.withLock { backendGuard.withLock { store.change { Snapshot() } } } }
}

package com.code101.tasks.data.sync

import android.content.Context
import androidx.work.*
import com.code101.tasks.domain.repository.Session
import com.code101.tasks.domain.repository.SessionStatus
import com.code101.tasks.domain.repository.TasksRepository
import dagger.hilt.android.qualifiers.ApplicationContext
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.flow.*
import kotlinx.coroutines.launch
import java.util.concurrent.TimeUnit
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class SyncScheduler @Inject constructor(@ApplicationContext private val context: Context,
    private val repository: TasksRepository, private val session: Session) {
    fun start(scope: CoroutineScope) {
        val manager = WorkManager.getInstance(context)
        val constraints = Constraints.Builder().setRequiredNetworkType(NetworkType.CONNECTED).build()
        manager.enqueueUniquePeriodicWork("tasks-periodic", ExistingPeriodicWorkPolicy.KEEP,
            PeriodicWorkRequestBuilder<SyncWorker>(15, TimeUnit.MINUTES).setConstraints(constraints)
                .setBackoffCriteria(BackoffPolicy.EXPONENTIAL, 30, TimeUnit.SECONDS).build())
        scope.launch {
            combine(repository.online, session.status,
                repository.snapshot.map { it.outbox.size }.distinctUntilChanged()) { online, status, count ->
                online && status == SessionStatus.SignedIn && count > 0
            }.distinctUntilChanged().collect { ready ->
                if (ready) {
                    manager.enqueueUniqueWork("tasks-sync", ExistingWorkPolicy.KEEP,
                        OneTimeWorkRequestBuilder<SyncWorker>().setConstraints(constraints)
                            .setBackoffCriteria(BackoffPolicy.EXPONENTIAL, 30, TimeUnit.SECONDS).build())
                    runCatching { repository.sync() }
                }
            }
        }
    }
}

package com.code101.tasks.data.sync

import android.content.Context
import androidx.hilt.work.HiltWorker
import androidx.work.CoroutineWorker
import androidx.work.WorkerParameters
import com.code101.tasks.data.auth.AuthStateManager
import com.code101.tasks.domain.repository.SessionStatus
import com.code101.tasks.domain.repository.TasksRepository
import dagger.assisted.Assisted
import dagger.assisted.AssistedInject

@HiltWorker
class SyncWorker @AssistedInject constructor(@Assisted context: Context, @Assisted parameters: WorkerParameters,
    private val repository: TasksRepository, private val auth: AuthStateManager) : CoroutineWorker(context, parameters) {
    override suspend fun doWork(): Result {
        if (auth.status.value == SessionStatus.Checking) auth.restore()
        if (auth.status.value != SessionStatus.SignedIn) return Result.success()
        return try {
            repository.sync()
            if (repository.hasPending()) Result.retry() else Result.success()
        } catch (e: kotlinx.coroutines.CancellationException) { throw e } catch (_: Exception) { Result.retry() }
    }
}

class QueryEnums : Converter.Factory() {
    override fun stringConverter(type: Type, annotations: Array<Annotation>, retrofit: Retrofit): Converter<*, String>? {
        if (type !in setOf(TasksApi.SortListTasks::class.java, TeamsApi.SortListTeams::class.java,
            ProjectsApi.SortListProjects::class.java, TaskStatus::class.java, TaskPriority::class.java)) return null
        return Converter<Any, String> { value -> when (value) {
            is TasksApi.SortListTasks -> value.value
            is TeamsApi.SortListTeams -> value.value
            is ProjectsApi.SortListProjects -> value.value

@Module
@InstallIn(SingletonComponent::class)
object NetworkModule {
    @Provides @Singleton
    fun retrofit(settings: BackendSettings, session: Session): Retrofit {
        val client = OkHttpClient.Builder().followRedirects(false).followSslRedirects(false)
            .addInterceptor { chain ->
                val target = settings.url.value.toHttpUrl()
                val url = chain.request().url.newBuilder().scheme(target.scheme).host(target.host).port(target.port).build()
                chain.proceed(chain.request().newBuilder().url(url).build())

import androidx.lifecycle.viewModelScope
import com.code101.tasks.domain.model.*

import kotlinx.coroutines.channels.Channel
import kotlinx.coroutines.flow.*
import kotlinx.coroutines.launch
import javax.inject.Inject

data class ScreenState(val data: Snapshot = Snapshot(), val busy: Boolean = false,
    val problem: ApiProblem? = null, val connectionName: String? = null)
open class ScreenModel(protected val repository: TasksRepository) : ViewModel() {
    private val operation = MutableStateFlow(ScreenState())
    val state = combine(repository.snapshot, operation) { data, op -> op.copy(data = data) }
        .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), ScreenState())
    val online = repository.online
    val backendKind = repository.backendKind
    val baseUrl = repository.baseUrl
    private val events = Channel<Unit>(Channel.BUFFERED)
    val saved = events.receiveAsFlow()
    protected fun action(block: suspend () -> Unit) {
        if (operation.value.busy) return
        viewModelScope.launch {
            operation.value = operation.value.copy(busy = true, problem = null)
            try { block() }
            catch (e: CancellationException) { throw e }
            catch (e: ApiFailure) { operation.value = operation.value.copy(problem = e.problem) }
            catch (_: IllegalArgumentException) { operation.value = operation.value.copy(problem = ApiProblem("bad-request", "", 400)) }
            catch (_: IllegalStateException) { operation.value = operation.value.copy(problem = ApiProblem("queue-not-empty", "", 0)) }
            catch (_: Exception) { operation.value = operation.value.copy(problem = ApiProblem("offline", "", 0)) }
            finally { operation.value = operation.value.copy(busy = false) }
        }
    }
    fun sync() = action { repository.sync() }
    fun save(projectId: String, id: String?, key: String, draft: TaskDraft, original: TaskItem?) = action {
        repository.save(projectId, id, key, draft, original); events.send(Unit); repository.sync()
    }
    fun resolve(id: String, keep: Set<String>) = action { repository.resolve(id, keep) }
    fun retry(id: String) = action { repository.retry(id) }
    fun discard(id: String) = action { repository.discard(id) }

    fun backend(kind: Backend, url: String) = action { repository.backend(kind, url) }
    fun connection() = action {

    }

                    busy = true

**File: `tools/convert_icons.py`**
```python
# Convert only the CC0 24x24 stroke shapes used by this pack.
from pathlib import Path
import sys
import xml.etree.ElementTree as ET

ICONS = ["arrows/log-in", "arrows/log-out", "arrows/refresh-cw", "users/team",
         "files/folder", "ui/list", "ui/plus", "ui/settings", "devices/wifi-off",
         "communication/message-square"]

def path_data(node):
    a = node.attrib
    tag = node.tag.split("}")[-1]
    if tag == "path":
        return a["d"]
    if tag == "line":
        return f'M{a["x1"]},{a["y1"]} L{a["x2"]},{a["y2"]}'
    if tag in ("polyline", "polygon"):
        return "M" + " L".join(a["points"].split()[i] + "," + a["points"].split()[i+1]
                              for i in range(0, len(a["points"].split()), 2)) + (" Z" if tag == "polygon" else "")
    if tag == "circle":
        x, y, r = (float(a[k]) for k in ("cx", "cy", "r"))
        return f"M{x-r},{y} a{r},{r} 0 1,0 {2*r},0 a{r},{r} 0 1,0 {-2*r},0"
    if tag == "rect":
        x, y = float(a.get("x", 0)), float(a.get("y", 0))
        w, h = float(a["width"]), float(a["height"])
        return f"M{x},{y} h{w} v{h} h{-w} Z"
    raise ValueError(f"Unsupported SVG shape: {tag}")

def main():
    source = Path(sys.argv[1])
    target = Path("app/src/main/res/drawable")
    target.mkdir(parents=True, exist_ok=True)
    for icon in ICONS:
        svg = ET.parse(source / (icon + ".svg")).getroot()
        lines = ['<vector xmlns:android="http://schemas.android.com/apk/res/android"',
                 '    android:width="24dp" android:height="24dp"',
                 '    android:viewportWidth="24" android:viewportHeight="24">']
        for node in svg:
            data = path_data(node)
            lines.append('    <path android:fillColor="@android:color/transparent" android:strokeColor="#FF000000"')
            lines.append('        android:strokeWidth="2" android:strokeLineCap="round" android:strokeLineJoin="round"')
            lines.append(f'        android:pathData="{data}" />')
        lines.append('</vector>')
        name = 'ic_' + icon.split('/')[-1].replace('-', '_') + '.xml'
        (target / name).write_text('\n'.join(lines) + '\n', encoding='utf-8')
    print("Converted 10 CC0 icons")

if __name__ == "__main__":
    main()
```

## How it works
The debug APK is installable locally. An AAB is a publishing input, not an installable APK. Release runs R8 and requires both configured origins to be HTTPS without credentials. With no upload configuration it deliberately uses the local debug key and emits NOT FOR STORE.

Ignored keystore.properties holds only key path and alias; passwords come from process environment. No SDK location, private key or password file is shipped. Public endpoint configuration is not a secret, but example.invalid is intentionally unusable.

The emulator API may use 10.0.2.2. Identity must remain localhost to match the issuer, so reverse port 8180. USB phones have no 10.0.2.2 alias: reverse both 8000/8180 and select localhost for the API. Backend presets intentionally share 8000; only one server runs at once.

The manual helper consumes the finished backend's existing Compose files and fake .env.example without editing them. Its shell stays inside the tasksteams lock throughout device work. Finally removes only its project, volumes, orphans and built API image, not shared postgres/Keycloak image caches. PrintPlan describes the branch without starting Docker. No final backend/device session is claimed.

## Common mistakes
**Historical diagnostic:** deliberately triggered in an isolated authoring copy before execution was stopped. Copied from evidence/05-gradle-error.txt, not reconstructed from memory; it does not establish a successful final build.

```text
> Release API and issuer must use HTTPS without credentials
BUILD FAILED in 10s
```

| Symptom | Cause | Fix |
|---|---|---|
| Diagnostic above | Release was asked to use an HTTP origin. | Use HTTPS for both API and issuer. Local cleartext belongs only in debug. |
| Empty cache after changing accounts | Cross-account records are intentionally hidden | Sign out with explicit delete-offline-data before switching users. Never weaken the guard. |
| A write waits after a lost response | The server may already have committed | Keep the saved body/key and retry it, rather than changing the body under that key. |
| A conflict does not retry automatically | A stale version needs a user decision | Open Sync queue, review mine/theirs and resolve with the new server version. |

## Best practice
Keep upload signing material outside source control and distinguish an upload key from a debug key. Source: [Sign your app](https://developer.android.com/studio/publish/app-signing).
