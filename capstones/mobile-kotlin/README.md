## What is included
- Pinned wrapper/AGP/Kotlin/Compose, generated Retrofit interfaces and DTOs from an unchanged platform contract.
- AppAuth system-browser code + PKCE, a Keystore AES-GCM vault and serialized refresh/persist-before-use.
- MVVM ViewModels, lifecycle-aware StateFlow, typed navigation, localized copy and accessible control semantics.
- Teams, Projects, Task list, Task detail/comments, Create or edit task, Conflict sheet, Settings and Sync queue,
  plus Session check and Login. UI is isolated from Retrofit and Room by domain interfaces.
- Persisted backend preset/root selection, with a custom-host token-destination warning.
- A Room cache and transactional outbox with ordering, immutable sent request bodies, idempotency,
  quoted version ETags, explicit null merge patches, problem details, Retry-After, conflicts and WorkManager.
- APK/AAB configuration, no-backup rules, debug-only local HTTP, release HTTPS guard/R8, private signing guide.
- Ten Android vectors converted only from assets/art CC0 icons; source SVGs/license are added to each pack.

## Design clarifications and limits
1. Chapter 02 guards the placeholder; intended feature-route restoration and the delete-offline-data choice
   are integrated in 03 when the real screens/cache boundary exist.
2. A pending create can absorb edits only before sending starts. After an uncertain response its immutable
   body/key must be retried; later edits depend on it. This narrows the TDD wording to preserve idempotency.
3. Outbox seq is SQLite's integer primary key and UUID id has a unique index. SQLite cannot auto-generate a
   second non-primary-key integer alongside a text primary key. Parent id supports dependent comments.
4. The design's OutboxProcessor is the repository's sync() method in this teaching implementation, sharing
   one mutex with Worker callers. RoomStore rewrites a small bounded snapshot transactionally; large caches
   need per-row DAO writes before any performance claim. Startup/performance/durability targets are unmeasured.
5. Reproducible SVG conversion is scripted; equivalent Vector Asset Studio import steps are shown, not claimed
   to have been automated. Generated APIs/wrapper/schema files have explicit skip_lesson_check inventories.
6. M-01's literal http:// search must mean authored Kotlin feature/configuration code: XML namespace URIs,
   the unchanged contract, generated docs and tutorial prose necessarily contain http://.
7. WorkManager's 15-minute minimum is not a delivery deadline; force-stop/Doze/quotas can delay background work.
8. The demonstration example.invalid deep links are not owned/verified Android App Links. A real release needs
   owned HTTPS API/identity origins and a separately registered/verified link deployment if that is desired.

No new platform contract defect was established. Section 12.1 Decision behavior is consumed, not patched:
task-only If-None-Match, case-insensitive headers, JSON replay semantics, 413 and retryable outage handling.
The platform/backends and shared documentation/scripts were not edited.
