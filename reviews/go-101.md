# go 101 (all 12 lessons) walk-through by Sam

**Persona:** Sam, marketing, never coded. Used only what each lesson had already taught.
**Method:** unzipped `dist/packs/go-101-all.zip` into a clean temp folder. Typed every lesson's Steps literally into new modules (`go mod init example.com/code101/lessonNN`, the `go 1.22.0` edit, every file in lesson order), ran `go run .`, piped keyboard input for lessons 03, 09 and 12, attempted each starter before opening its solution, then deliberately triggered every Common-mistakes row. Judged against the quality checklist, `lessons-learned.md` and https://go.dev/doc/install. Go 1.27.4, Windows PowerShell 5.1. Nothing installed or uninstalled. The work folder was removed afterwards.
**Not simulated:** GUI steps (MSI/PKG installers, VS Code, the Go extension's tool prompt, Explorer buttons, `File > Open Folder`). They are judged by reading and marked "(read-only)". Input was piped, not typed live, so the terminal echo of typed lines was not seen.
**Environment checks:** GOPATH (`C:\Users\<me>\go`), GOFLAGS (empty), GO111MODULE (unset), GOTOOLCHAIN (`auto`). None of them affected a lesson. Nothing was created outside each lesson's folder.

## Mechanical checks
- **Code blocks:** every lesson `main.go`, `go.mod`, `scan-demo/main.go`, `receipt/receipt.go`, `expense.go` and `check.go` is identical to the pack's `code/` (`fc`). The starters and solutions in the pack match the text shown in each lesson (my own exercise edits differ only in style, for example a different loop form in lesson 05, and a TODO comment I left in lesson 12).
- **Expected output:** every block is what really prints, for lessons 01 to 12. Lesson 03 gives 12.00/92.00/46.00 and the exercise 8.00/88.00/44.00. Lesson 09 gives the wrapped `strconv.Atoi: parsing "tea": invalid syntax`. Lesson 12 gives the CSV `label,cents` / `Coffee,350`.
- **go.mod:** `go mod init` printed `go: creating new go.mod: module ...` and wrote `go 1.27.4`, exactly as lesson 01 shows. After the hand edit to `go 1.22.0` every lesson ran.
- **Exercises:** all 12 starters ran as stated before editing and all 12 attempts reached the stated output (try03 gives 44.00 each, try12 gives `Count: 1`).
- **Common mistakes:** all 24 rows reproduced with the same message text. Line and column numbers always differ because the table's code is not in the lesson (finding 31). Two rows differ in wording from what the lesson's own code produces (findings 22 and 25).
- **Install text vs https://go.dev/doc/install:** the Windows, macOS and Linux steps agree with the official page (MSI, default folder Program Files, reopen the terminal; PKG installs to `/usr/local/go` and edits PATH; Linux `rm -rf` plus `tar -C /usr/local` plus the `export PATH` line in `~/.profile`; `go version`). `go1.27.4.windows-amd64.msi` returns HTTP 200 and 1.27.4 is the current stable at https://go.dev/dl/. Differences are in findings 6 and 7.

## Top 5 fixes
1. **Say where the pack zip comes from** (finding 1). Without it nothing in "compare with this finished example" or in the exercises can start.
2. **Make the exercises exercises** (finding 29) and **fix the starter-copy sentence** (finding 9). Remove the answer from the Try it intro, and say "rename `starter` to `try01`".
3. **Add the likeliest real errors to Common mistakes** (findings 4, 15, 30, 32, 34): wrong folder (`go.mod file not found`), `$80`/`15%` input, value-receiver silent no-op, mistyped import path (with "do not run go get"), and `go run main.go` in lesson 12. Also fix the table rows that do not match the lesson's own code (22, 25).
4. **Rebalance the heavy lessons and the time claims** (findings 13, 14, 23, 24, 27, 30, 35): lessons 03, 07, 10 and 12 are too dense for 25 or 45 minutes. Define or remove "method" (lesson 09), "nil map", "octal", "object", "32-bit int".
5. **Cut the repeated boilerplate and noise** (findings 3, 8, 38): drop the go.mod edit and its jargon paragraph, drop the "Maintainer smoke result" blocks, and link to one shared "how every lesson works" page. Also escape the `||` in the lesson 04 table (finding 17) and add the "change age and rerun" step (finding 18).
