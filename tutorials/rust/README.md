# Rust 101 - Zero to Hero

Start with lesson 01; no programming or command-line experience required. Every lesson shows all files and a no-download exercise route. Optional source: https://github.com/Uee03/Code101 under `source/rust/101-zero-to-hero` (choose **Code > Download ZIP**, or clone the repository). If using that ZIP, Windows: right-click **Extract All**; macOS: double-click; Linux: use the file manager's Extract action. Open `Code101-main/source/rust/101-zero-to-hero`. Phase archives are generated conveniences, not a required download.

Allow 30-35 minutes for most lessons, 60-90 for installation, 40-50 for 08, 50-60 for 09, and 100-120 for project 12 in two sittings. See [the glossary](GLOSSARY.md) for definitions and [_STATE.md](_STATE.md) for verification details.
