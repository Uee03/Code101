# Contract/design findings (2026-11-23)

No platform or sibling capstone file was edited. Copies of openapi.yaml, the smoke database, realm and Python backend remain byte-identical to their sources. The client follows platform TDD 12.1's Decision column: task-only If-None-Match; 409 last_lead on demotion/removal; case-insensitive header lookup; JSON comparison for idempotent data; ignore rate headers on health; visible errors for 400/405/413/415/503. tasks-smoke has all scopes: no real missing-scope rejection is claimed.

1. Client TDD W-08 says no tokens in URLs, while W-11 requires the OIDC id_token_hint logout parameter. angular-oauth2-oidc 22.0.2 uses a logout navigation containing the ID-token hint. This implementation follows W-11 and explicitly documents that narrow exception: access/refresh tokens never enter URLs; the ID-token hint only goes to the issuer's discovered end-session endpoint. Referrer-Policy is no-referrer; no token is printed. A strict no-ID-token-in-any-URL policy needs a separately designed transport (and CSP changes if using a cross-origin form).
2. Docker Hub marks nginxinc/nginx-unprivileged archived and directs users to nginx/nginx-unprivileged. The approved 1.30-alpine tag resolves and is retained for fidelity to the TDD; migrate only after approving and smoke-checking a replacement pin. This is a dependency maintenance issue, not an API defect.
3. The generator reports application/merge-patch+json and application/json as the same $Json variant and selects application/json. The Python backend accepts that contract media type and the captured patch succeeds. Do not edit the contract locally to silence the warning.
4. Node execution works, but the minimal root injector uses Angular's private INJECTOR_SCOPE export only in scripts/node-client.ts. Browser code uses public APIs. An Angular upgrade must re-run the spike; fallback is a model-typed fetch smoke with an explicit W-05 verification deviation, never an undisclosed replacement.

Only the supplied final Python backend was used. Compatibility with other backends is a contract expectation, not a reported cross-backend smoke result. Browser sign-in, storage inspection, six-minute refresh, step-up, sign-out, visual/keyboard/assistive-technology checks and conflict-dialog interaction remain human acceptance tasks. No new platform API defect was observed in the smoke scenario.
