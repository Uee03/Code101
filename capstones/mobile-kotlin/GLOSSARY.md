# Mobile Kotlin glossary

Terms used by the five chapters. All final chapters are written (not run).

| Term | Meaning |
|---|---|
| AAB | Android App Bundle: a publishing input from which a distribution service makes device-specific APKs; it is not directly installed like an APK. |
| AES-GCM | Authenticated symmetric encryption. A secret AES key encrypts bytes; the GCM authentication tag detects tampering. Each encryption needs a fresh IV. |
| AGP | Android Gradle Plugin: the plugin that compiles Android sources, merges manifests/resources and creates APKs/AABs. |
| Android App Link | An HTTPS link verified as belonging to an app through domain ownership; the example.invalid demonstration here is not one. |
| Android Keystore | Android-managed cryptographic key storage. A non-exportable key can perform encryption/decryption without revealing its raw bytes. |
| AndroidX | The maintained Android Jetpack library namespaces used by Compose, lifecycle, Room and WorkManager. |
| APK | Android Package: an installable Android application artifact. |
| AppAuth | A library implementing browser-based OAuth/OIDC flows, PKCE, request state and token exchange; the app never handles the browser password. |
| Application id | The installation identity of an Android app. com.code101.tasks.kotlin and com.code101.tasks.flutter install separately. |
| Artifact | A build output such as an APK, AAB, generated client or exported Room schema. |
| Authenticator | The OkHttp callback that may produce one retry request after an authentication rejection. |
| Authorization code | A short-lived browser-flow result exchanged for tokens; it is not itself an API bearer token. |
| Backoff | An increasing retry delay after failure. Exponential backoff grows the delay with attempts and is capped here. |
| Bearer token | A credential sent in the Authorization header; whoever holds it can act within its validated claims and permissions. |
| BOM | Bill of materials: a dependency platform selecting mutually compatible library versions, such as the Compose BOM. |
| Build type | An Android configuration such as debug or release selecting endpoint values, shrinking and signing behavior. |
| BuildConfig | Generated constants for the selected Android build variant; public endpoint/client settings come from here. |
| Cache | A local copy of previously obtained server data so screens can render without a successful new request. |
| Channel | A coroutine communication primitive used here for one-off save-navigation effects rather than persistent UI state. |
| Ciphertext | Encrypted bytes. In this app a DataStore holds ciphertext while the key remains in Android Keystore. |
| Clean layers | Dependency organization in which UI and data depend on domain interfaces/models, not on each other. |
| Cold start | Starting a process that is not already alive. The final cached-start timing has not been measured. |
| Composable | A Jetpack Compose function describing UI from current state instead of imperatively editing view widgets. |
| Coroutine | A suspendable unit of Kotlin work; suspending for an operation does not require blocking the UI thread. |
| Cursor | An opaque pagination value copied from page.nextCursor. Clients neither construct nor decode it. |
| Custom Tab | An external browser surface used for identity interaction rather than an embedded app WebView. |
| DAO | Data access object: a Room interface/class whose annotated queries and writes are generated by KSP. |
| DataStore | Android asynchronous persistent key-value storage; settings are ordinary preferences, while auth holds only an encrypted blob. |
| Deep link | A path/intent selecting a destination inside the app. A signed-out app retains a recognized intended path until sign-in. |
| Dependency injection | Supplying dependencies from a composition root instead of constructing concrete services inside every screen. |
| DoS/Doze | DoS is denial of service; Doze is Android power-saving behavior that can delay background jobs. They are unrelated mechanisms. |
| DP | Density-independent pixel, the Android unit for layout and minimum 48-dp touch-target design. |
| DTO | Data transfer object generated from the API schema. Domain models intentionally do not expose Retrofit/Room types. |
| ETag | An HTTP resource version identifier; this contract uses a quoted integer version, such as a quoted 3. |
| Flow | A coroutine stream of values that can be observed over time, including database invalidations. |
| GCM tag | The authentication data used by AES-GCM to reject changed ciphertext instead of producing untrusted plaintext. |
| Gradle | The task-based build system. A committed wrapper selects it without a global installation. |
| Hilt | Android dependency injection built on Dagger. Generated bindings provide repositories, ViewModels and workers. |
| HTTP status | The response code describing success or a condition such as 401 auth rejection, 412 stale version, 422 invalid fields or 429 throttling. |
| Idempotency key | A stable operation identifier sent on create. Replaying the same key/body returns the original result, not a second create. |
| If-Match | A request precondition carrying the version being edited. A missing version gives 428; a stale version gives 412. |
| If-None-Match | A conditional read header. This client may rely on it only for tasks until platform v1.1 decides otherwise. |
| IV | Initialization vector: fresh per-encryption input to AES-GCM, stored alongside ciphertext and not a secret key. |
| JBR | JetBrains Runtime: the JDK bundled with Android Studio; it runs Gradle but is not shipped with the app. |
| JDK | Java Development Kit: the runtime/compiler tools used to build JVM/Android code. Bytecode target 17 is separate from build JDK 25. |
| Jetpack | Android libraries covering UI, lifecycle, storage, navigation and background work. |
| Jitter | Random addition to retry delay so clients do not all retry at the same instant. |
| JSON Merge Patch | A JSON object describing changed fields: absent leaves a field unchanged and explicit null clears a nullable field. |
| JSON Pointer | A path such as /title naming the invalid field in a problem errors array. |
| Key rotation | Issuing a replacement credential and invalidating the old one; refresh tokens in this realm rotate on use. |
| KSP | Kotlin Symbol Processing: compile-time generation used by Hilt and Room, not a test suite. |
| Lifecycle-aware collection | Observing UI flows only during the appropriate Android lifecycle state using collectAsStateWithLifecycle. |
| Live region | Accessibility semantics asking a screen reader to announce changed content; the offline banner uses polite announcements. |
| Manifest overlay | A source-set-specific AndroidManifest merged into a variant, such as a debug-only network-config reference. |
| Material 3 | Compose components/theme defaults for controls and layout. Manual contrast/font/TalkBack review remains necessary. |
| Migration | A versioned transformation preserving stored data when a database schema changes. |
| Mutex | A coroutine mutual-exclusion lock allowing one refresh or drain critical section at a time. |
| MVVM | Model-View-ViewModel: UI renders observable ViewModel state and sends user events to it. |
| Namespace | The Android package for generated R/BuildConfig classes; it may differ from the application id. |
| OAuth | The authorization framework supplying delegated credentials; OIDC adds identity information to it. |
| OIDC | OpenID Connect: identity on top of OAuth, including discovery, ID tokens and browser session logout. |
| Outbox | A durable ordered list of local writes waiting for acknowledgement, stored transactionally with their optimistic cache changes. |
| PKCE | Proof Key for Code Exchange: a random verifier is bound to the code request by its S256 challenge, protecting an intercepted code. |
| Plaintext | Unencrypted bytes; tokens must not be stored this way in Room, ordinary settings, logs or source files. |
| Problem details | RFC 9457 error data with type/title/status and optional field pointers, traceId and retry metadata. |
| Public client | An app unable to protect a distributed client secret. Mobile uses code+PKCE, never a secret or password grant. |
| R class | Generated Android resource identifiers, such as R.string.title_field and R.drawable.ic_team. |
| R8 | The Android release optimizer/shrinker. Consumer and app rules preserve structures needed at runtime. |
| Redirect scheme | The custom URI scheme registered for the browser return: com.code101.tasks, shared by the mobile twins. |
| Repository | The domain-facing boundary coordinating remote API, cache, outbox and screen events. |
| Retrofit | Typed HTTP service interfaces over OkHttp; these interfaces/models are generated from OpenAPI. |
| Retry-After | A case-insensitive HTTP header specifying seconds or a date before a retry; persisted outbox delays honor it as a lower bound. |
| Room | Android SQLite mapping with entities, generated DAOs, observable queries, transactions and exported schemas. |
| Route | A destination plus arguments. Serializable Kotlin routes correspond to the same logical paths as Flutter. |
| S256 | The SHA-256-based PKCE challenge method, selected by AppAuth for the code verifier. |
| Schema export | Room-generated JSON documenting the database version; ship it but never hand-edit it. |
| Scope | A permission requested/granted with a token. The app asks for identity and task read/write, never tasks:admin. |
| Semantics | Accessibility information describing control labels, state, actions and announcement behavior to assistive technology. |
| Serialization | Encoding/decoding typed records as wire JSON or persisted domain payload JSON. |
| Single-flight refresh | Sharing one in-flight refresh so simultaneous requests do not rotate the same refresh credential twice. |
| Snapshot | One immutable cache projection containing teams/projects/tasks/comments/outbox/account; presentation delivery can lag a commit. |
| StateFlow | A coroutine flow exposing its latest state value. UI observes it; transactional decisions read committed storage instead. |
| Static comparison | Checking lesson text against source without executing recipe steps. It is not a build, smoke PASS or device verification. |
| TalkBack | Android screen reader used in a human accessibility review. |
| Transaction | An all-or-nothing database operation; local data change and outbox insertion commit together. |
| Typed navigation | Navigation destinations defined as serializable Kotlin types rather than hand-concatenated route argument strings. |
| Upload key | A private signing key managed outside the repository. The default teaching AAB uses a debug key and is NOT FOR STORE. |
| UUID | A 128-bit identifier represented here as text for domain ids and stable operation keys. |
| Vector drawable | An Android XML image using paths in a viewport rather than a bitmap, converted here only from CC0 art. |
| ViewModel | A lifecycle-aware state/event owner outside composables. It survives activity configuration changes. |
| WebView | An embedded web surface; it is deliberately not used to collect identity-provider credentials. |
| WhileSubscribed | A Flow sharing policy; the 5000-ms grace period keeps UI state warm across brief subscriber gaps. |
| Worker | A WorkManager job that can be retried under system scheduling/constraints rather than a permanently running server. |
| WorkManager | Android persistent background scheduling with unique work, network constraints and a minimum 15-minute periodic interval. |
| Wrapper | Generated Gradle launch scripts/jar plus version/checksum properties committed for reproducible bootstrapping. |

## Platform and identity terms

- SDK: Software Development Kit; here the installed Android platform jars, build-tools and device tools.
- compileSdk: the API surface available when compiling; this project explicitly selects installed API 37.2.
- targetSdk: the Android behavior/policy level the app declares it has adopted; approved value here is 36.
- minSdk: the oldest Android API level on which the app permits installation; here 26.
- Issuer: the exact identity-provider identifier advertised by discovery and in a token, including scheme/host/path.
- Discovery: reading the issuer's well-known document to obtain its authorization, token and logout endpoints.
- Nonce: a random request value binding an identity response to its original authorization request.
- OAuth state parameter: a random value binding a browser response to the app request, distinct from UI state.
- SSO: single sign-on, the identity provider's browser session reused across app sign-ins until it ends.
- TLS: Transport Layer Security, used by HTTPS to protect network traffic and authenticate the server endpoint.
- RFC: a published protocol specification, such as RFC 9457 problem details or RFC 7396 JSON Merge Patch.
