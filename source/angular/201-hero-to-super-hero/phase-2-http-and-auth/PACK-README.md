# Angular 201, Phase 2: HTTP and auth

Source pack for lessons 04 to 06. Status: written, not yet run (see `tutorials/angular/_STATE.md`).

| Folder | Lesson | Status | You build |
|--------|--------|--------|-----------|
| `04-http-interceptors-and-problem-json` | HTTP interceptors and problem+json error handling | written (not run) | A new project `task-board`, a Node mock API, three interceptors, an `ApiProblem` parser and a demo page |
| `05-typed-api-client-from-openapi` | A typed API client from OpenAPI (ng-openapi-gen) | written (not run) | A mini OpenAPI file, a generated client in `src/app/api` and an Explorer page that calls eight operations |
| `06-oidc-login-pkce-and-route-guards` | OIDC login with PKCE and route guards (Keycloak realm tasksteams) | written (not run) | `AuthService`, memory-only token storage, `authInterceptor`, `authGuard`, `adminGuard`, login, callback, home and admin pages |

`code/` is the whole project; `exercise/starter/` and `exercise/solution/` are overlay files; `verify.json` is not run yet. No `package-lock.json`: `npm install` creates it. In lessons 05 and 06 the folder `src/app/api/` is generated by `npm run api:gen` (run automatically by `npm start` and `npm run build`) and is git-ignored.

## Needs and how to run
Node 26.13.1 target, Angular 22.3.0, TypeScript 6.0.3. Two terminals in `code/`: `npm run mock` (mock API on port 8000, not a real backend) and `npm start` (app on 4200). Stop the mock before starting a real platform backend: both use port 8000. Lesson 06 also needs Keycloak (Docker, temporary) from `capstones/platform/source/phase-3-identity/03-keycloak-identity/code` (`docker compose -p platform up -d --wait keycloak`, then `npm run mock:auth`); remove it with `docker compose -p platform down -v`.
