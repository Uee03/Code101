# rust 101 walk-through by Sam (marketing, no coding experience)

Date: 2026-11-23. Windows PowerShell 5.1, rustc 1.100.0 / cargo 1.100.0 (already installed; nothing installed or removed).
Method: unzipped `dist/packs/rust-101-all.zip` to a clean temp folder; typed every lesson's Steps literally into new projects
(`cargo new --vcs none --name ... lessonNN`), ran `cargo run --quiet` with piped keyboard input, attempted every exercise starter
before opening its solution, and deliberately triggered the 'Common mistakes' errors. The phase zips were placed in a sandbox
`Downloads` folder, and `$HOME` pointed at the sandbox, so the real home folder was not touched.
Not testable here: the Windows installer/Visual Studio flow, Explorer "Extract All" and Notepad dialogs. The install text was judged
only against https://www.rust-lang.org/tools/install and the rustup MSVC page. The installer URL returns 200.

Checked and fine:
- Every line of every `code/`, starter and solution file appears in its lesson (0 missing lines in 12 lessons).
- All 12 programs print exactly the Expected output, and all 12 captured `diagnostics/compiler-output.txt` files are byte-identical to what `rustc --edition=2024 --color never error.rs` prints today.
- Every exercise starter is solvable from its lesson, and each solution produces the stated output.
- Install text is consistent with the official page: x64 / ARM64 buttons, MSVC prerequisite, new terminal after install.
- Ownership explanations in lessons 07 and 10 are accurate and gentle (move, clone, `&`, `&mut`, deref to `&str`).

Time (my estimate for a first-timer, not measured): L01 60+ min; L02 to L07 and L10 to L11 about 25 to 35 min;
L08 about 40 min; L09 about 45 min; L12 about 90 to 120 min typing 150 lines blind.
