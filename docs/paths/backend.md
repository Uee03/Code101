# Learning path: Backend

Goal: build the Tasks and Teams API in one language, then pass the shared conformance script. **Choose one language** (Python, C#, Go or Rust) and follow the steps in order. Tick each box as you finish. `(planned)` means the lesson is not written yet.

Lessons carry a draft notice (written, not yet run); see [START-HERE](../START-HERE.md#how-to-read-the-draft-notice).

## Time estimate

Each lesson is about 25 minutes. Capstone times come from the "Estimated learner time" row of each TDD.

| Language | Lessons | Lesson time | Platform capstone | Backend capstone | Total |
|----------|---------|-------------|-------------------|------------------|-------|
| Python | 65 | about 27 h | 5 h | 9 h | about 41 h |
| C# (ASP.NET Core) | 65 | about 27 h | 5 h | 8 h | about 40 h |
| Go | 64 | about 27 h | 5 h | 12 h | about 44 h |
| Rust | 64 | about 27 h | 5 h | 8 h | about 40 h |
