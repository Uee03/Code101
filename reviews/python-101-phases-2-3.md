# python 101 Phases 2 and 3 (lessons 05 to 12) walk-through by Sam

**Persona:** Sam, marketing, never coded. Assumed Phase 1 finished (Python 3.15.2 and VS Code installed). Used only what earlier lessons had taught; a term used before its definition is logged.
**Method:** unzipped `python-101-phase-2-building-blocks.zip` and `python-101-phase-3-real-programs.zip` into a clean `%TEMP%\sam-python` folder. Typed every file of every lesson into new files, with each intermediate version, in lesson order. Ran them with `python` on Windows PowerShell 5.1, piping input (for example `"80`n15" | python x.py`). Typed each exercise starter, attempted it, then ran the solution. Triggered the errors in each Common-mistakes table and compared the real message with the table. Ran the `venv` and `pip` steps for real. Compared every typed file with the pack's `code`, `exercise/starter` and `exercise/solution` using `fc.exe`.
**Not simulated:** GUI steps (VS Code Explorer, right-click Extract All, VS Code pop-ups). Findings on those come from reading and are marked "(read-only)". Times are my estimate for a first-timer, not a stopwatch.

## Mechanical checks
- **Code matches source:** PASS. Every lesson code block, starter and solution is byte-identical to the pack (`fc.exe`: no differences, 05 to 12).
- **Expected output is what prints:** PASS for all 8 lessons when input is piped (the prompts run together on one line, as the lesson captures show). Also confirmed: the lesson 08 CSV has CRLF row endings, the lesson 09 sequence `ten, -1, 30, $80, -5, 80.50` and the lesson 12 menu sequence `1, Tea, 250, 2, 3, 4`.
- **Common-mistakes text:** matches word for word for 05 (both), 06 (both), 07 (both), 08 (`ValueError: I/O operation on closed file.`), 09 (all four), 10 (`ceill`), 11 (both), 12 (`AssertionError`). Differences are in findings 8, 17, 18 and 19.
- **Exercises:** every starter runs and gives the wrong or placeholder answer. Every solution gives the stated output (`3 2 1 Go!`, `60.00`, `7`, journal appends across runs, `22.50`, `Seconds: 180`, `Ada: 500 / Lin: 0`, `Expense count: 1`). All are solvable from the lesson text alone.
- **Environment steps (lesson 10):** `python -m venv .venv` took about 7 seconds and printed nothing. The `sys.prefix` check printed `True`. `pip install` of `colorama==0.4.6` printed nothing and the version check printed `0.4.6`. `main.py` ran identically with the system Python and the venv Python. Activation is never needed, as the lesson says.
