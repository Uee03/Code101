# Start here

Code101 teaches programming in three levels: **101** (zero to hero), **201** (hero to super hero) and **301** (super hero to legendary).

**You have free choice.** Learn any track, in any order, at any level. Then apply it in a capstone with any backend and any client: for example ASP.NET and Flutter, or Go and React. See [capstones](../capstones/README.md) for the pairing table and recommended lessons. Nothing is a gate.

Prefer a suggested order? The path pages below list lessons in a sensible sequence with tick boxes.

## Learn by track

Browse [tutorials](../tutorials): Python, C#, Go, Rust, Web (HTML, CSS, TypeScript), Angular, React, Flutter, Kotlin, Databases, Docker, Design Patterns, System Architecture and Ollama. Each has 101, 201 and (except the four client frameworks) 301.

## Suggested paths by goal

| I want to build | Path | Choose |
|-----------------|------|--------|
| A web API and database (the backend) | [Backend path](paths/backend.md) | Python, C#, Go or Rust |
| A website (the web client) | [Web path](paths/web.md) | Angular or React |
| A phone app (the mobile client) | [Mobile path](paths/mobile.md) | Flutter or Kotlin |

If you have never coded before, start with the language 101 lessons in the path you pick. You do not need to know which language is "best": every choice reaches the same finished project.

## What you build

All paths end in a capstone for the same product, **Tasks and Teams**. Every client and every backend follows one shared contract (the `platform` capstone), so any client works with any backend.

- Platform contract: [capstones/platform](../capstones/platform/README.md)
- Backends: [Python](../capstones/backend-python/README.md), [ASP.NET](../capstones/backend-dotnet/README.md), [Go](../capstones/backend-go/README.md), [Rust](../capstones/backend-rust/README.md)
- Web clients: [Angular](../capstones/web-angular/README.md), [React](../capstones/web-react/README.md)
- Mobile clients: [Flutter](../capstones/mobile-flutter/README.md), [Kotlin](../capstones/mobile-kotlin/README.md)
- No-source practice projects: [practice capstones](../capstones/_practice/README.md)

## Other tracks

Design Patterns, System Architecture, Ollama (local AI), Docker and Databases have their own folders under [tutorials](../tutorials). C, C++, Unity and Supabase are not written yet.

## How to read the draft notice

Lessons written after the "no smoke tests" decision start with a draft notice: the lesson and its code were written from the official docs but **not yet run**. Expect a few small errors, such as a changed version number or a typo in a command. If a step fails, read the error, check the tool's official docs, and report it as an issue on the repository. Level 101 lessons for Python, C#, Go, Rust, Web, Docker and Databases were run and verified earlier.

## Before you begin

Each path starts with primers (Git and GitHub, HTTP and REST, OpenAPI, OAuth2 and OIDC). Install the tools named in the first lesson of your language track. Docker, Postgres and Keycloak run in containers; the lessons show every config file.
