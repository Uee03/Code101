# 01. Setup and generated client

## Why it matters
A contract becomes useful to a phone when it can generate and build a client. Locking the tools and isolating local HTTP prevents development choices becoming release accidents.

## What you will build
A complete Android skeleton, Gradle wrapper, typed generated Retrofit client, scoped debug network policy and ten converted CC0 icons. The first screen says Setup ready. Requirements: M-01 to M-04.

**Execution status: written (not run).** The user stopped builds/smoke verification during authoring. Earlier captured diagnostics are labelled historical below; they do not verify this final snapshot. Commands here are instructions for a later session, not a claim they were run.

- Android Studio with its bundled JBR; SDK Platform 37.2 (`platforms/android-37.2`), build-tools 36.0.0, accepted SDK licenses; Python 3.10+ for standard-library helpers. No global Gradle is needed. The author machine has JDK 25; app bytecode targets Java 17.
- Studio Settings, Languages & Frameworks, Android SDK: enable Show Package Details and install the platform matching `android-37.2`; SDK Tools needs build-tools 36.0.0 and Platform-Tools. An emulator/browser is for later manual work only, not compilation.

```yaml
  description: |
    Domain: teams, members, projects, tasks, comments and an audit trail.
    Conventions (apply to every operation unless stated otherwise):

    - Version prefix `/v1`. `/health` is unversioned infrastructure.
    - Errors are RFC 9457 problem details (`application/problem+json`).
    - Lists use cursor pagination: `limit` and `cursor` in, `items` and `page.nextCursor` out.
```

```kotlin
import com.code101.tasks.BuildConfig
import okhttp3.HttpUrl
import okhttp3.Interceptor
import okhttp3.Response

object HttpUrlPolicy {
    fun requireAllowed(url: HttpUrl) {
        require(url.isHttps || (BuildConfig.DEBUG && url.scheme == "http" &&
            url.host in setOf("10.0.2.2", "localhost", "127.0.0.1")))
        require(url.username.isEmpty() && url.password.isEmpty())
    }
}
class UrlPolicyInterceptor : Interceptor {
    override fun intercept(chain: Interceptor.Chain): Response {
        HttpUrlPolicy.requireAllowed(chain.request().url)
        return chain.proceed(chain.request())
    }
```

```python
ICONS = ["arrows/log-in", "arrows/log-out", "arrows/refresh-cw", "users/team",
         "files/folder", "ui/list", "ui/plus", "ui/settings", "devices/wifi-off",
         "communication/message-square"]

def path_data(node):
    a = node.attrib
    tag = node.tag.split("}")[-1]
    if tag == "path":
        return a["d"]
    if tag == "line":
        return f'M{a["x1"]},{a["y1"]} L{a["x2"]},{a["y2"]}'
    if tag in ("polyline", "polygon"):
        return "M" + " L".join(a["points"].split()[i] + "," + a["points"].split()[i+1]
                              for i in range(0, len(a["points"].split()), 2)) + (" Z" if tag == "polygon" else "")
    if tag == "circle":
        x, y, r = (float(a[k]) for k in ("cx", "cy", "r"))
        return f"M{x-r},{y} a{r},{r} 0 1,0 {2*r},0 a{r},{r} 0 1,0 {-2*r},0"
    if tag == "rect":
        x, y = float(a.get("x", 0)), float(a.get("y", 0))
        w, h = float(a["width"]), float(a["height"])
        return f"M{x},{y} h{w} v{h} h{-w} Z"
    raise ValueError(f"Unsupported SVG shape: {tag}")

def main():
    source = Path(sys.argv[1])
    target = Path("app/src/main/res/drawable")
    target.mkdir(parents=True, exist_ok=True)
    for icon in ICONS:
        svg = ET.parse(source / (icon + ".svg")).getroot()
        lines = ['<vector xmlns:android="http://schemas.android.com/apk/res/android"',
                 '    android:width="24dp" android:height="24dp"',
                 '    android:viewportWidth="24" android:viewportHeight="24">']
        for node in svg:
            data = path_data(node)
            lines.append('    <path android:fillColor="@android:color/transparent" android:strokeColor="#FF000000"')
            lines.append('        android:strokeWidth="2" android:strokeLineCap="round" android:strokeLineJoin="round"')
            lines.append(f'        android:pathData="{data}" />')
        lines.append('</vector>')
        name = 'ic_' + icon.split('/')[-1].replace('-', '_') + '.xml'
        (target / name).write_text('\n'.join(lines) + '\n', encoding='utf-8')
    print("Converted 10 CC0 icons")

if __name__ == "__main__":
    main()
```

## How it works
Settings locate plugins/libraries; the catalog pins versions; AGP compiles with built-in Kotlin. Do not apply org.jetbrains.kotlin.android. Compose and serialization plugins use the Kotlin pin. The wrapper selects Gradle and checks its SHA-256.

openApiGenerate runs the pinned CLI in a Gradle JavaExec task, the documented alternative to the generator plugin. It produces APIs, DTOs and CollectionFormats, not the old template client/build. AnyType maps to JsonElement rather than an unserializable Kotlin Any. Response<T> retains status and headers. Generated code is never patched.

AGP 9 requires additional Kotlin directories in AndroidSourceSet.kotlin, not java or the legacy Kotlin source set. Installed compile platform 37.2 is explicit; targetSdk remains 36 as approved. Compile and target are different policies.

Main forbids cleartext. Only debug attaches a scoped network-security configuration, whose base policy still denies cleartext. The three exact exceptions allow neither arbitrary LAN addresses nor subdomains. HttpUrlPolicy repeats that rule in code. Backup and transfer exclusions cover ordinary and device-protected storage in addition to allowBackup=false.
