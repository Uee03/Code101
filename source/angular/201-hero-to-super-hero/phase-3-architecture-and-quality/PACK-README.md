Lessons 07, 08 and 09 continue from the project **as it was after lesson 05** (no sign-in), so they need only the mock API. Lesson 10 combines everything, including the sign-in files of lesson 06 (copied unchanged). `code/` is the whole project; `exercise/starter/` and `exercise/solution/` are overlay files; `verify.json` is not run yet. No `package-lock.json`: `npm install` creates it. `src/app/api/` is generated by `npm run api:gen` (run automatically by `npm start` and `npm run build`) and is git-ignored.

## Needs and how to run
Node 26.13.1 target, Angular 22.3.0, TypeScript 6.0.3, RxJS 7.8.2. Lessons 09 and 10 add `@angular/localize` 22.3.0; lesson 10 adds `angular-oauth2-oidc` 22.0.2. In `code/`: `npm install --no-audit --no-fund`, then two terminals: `npm run mock` (port 8000) and `npm start` (port 4200). German: `npm run start:de` (lessons 09 and 10), `npm run build:i18n` builds every locale. Lesson 10 with sign-in needs Keycloak from `capstones/platform` (Docker, temporary) and `authEnabled: true` in `src/environments/environment.ts`.
