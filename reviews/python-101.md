# python 101 Phase 1 (lessons 01 to 04) walk-through by Sam

**Persona:** Sam, marketing, never coded. Used only what each lesson had already taught.
**Method:** unzipped `dist/packs/python-101-phase-1-foundations.zip` into a clean temp folder, typed every step in order (including intermediate versions), attempted each starter before reading its solution, piped input for `input()` programs, then triggered every Common-mistakes error that a script can trigger. Python 3.15.2, Windows PowerShell 5.1.
**Not simulated:** the GUI steps (installers, VS Code, `code .`) cannot be run from a script. Findings on them are by reading, and are marked "(read-only)".

## Mechanical checks (all pass)
- Every lesson code block, final and starter, matches `source/.../code`, `exercise/starter` and `exercise/solution`. Differences are line endings only (see finding 35). The zip contents equal `source/`.
- Every "Expected output" block is what really prints. That covers all 5 rows of the lesson 04 ticket table and the grade checker with 30/60/90/101. The exercise solutions run and give the stated answers (22.50 for 90 and 4).
- Common-mistakes error text confirmed word for word: unterminated string literal, `Print` NameError, `nme` NameError, `"5" + 1` TypeError, `float('abc')`, `bill_text * tip_percent`, ZeroDivisionError, `int('ten')`, `if 5 = 5:`, IndentationError (line number differs by file), `can't open file`.
- Not matching the table: the `else` row (finding 28). Rows with no real message: `12,5` (22).

## What worked (for the author)
- Analogy-first voice (recipe, jars, cash register, road sign) is right for a 101 reader. Sentences are short.
- Every program in the pack runs and prints exactly what the lesson says.
- Each lesson has a starter and a solution, check questions, a best practice with a PEP citation.
- Lessons 02 and 03 are close to smooth: Sam finished each in a few minutes with only nits.

## Top 5 fixes
1. **Lesson 01 install flow** (findings 1, 2, 3, 6, 8): open the terminal before installing, one Windows route, check the Linux version, fix `code .` (new terminal, Trust dialog), and split or re-time it. This is where a real Sam is most likely to give up.
2. **Wrong statements** (4, 28, 25): `mkdir` does print a table in PowerShell; a misaligned `else` gives a SyntaxError/IndentationError, not "both run"; `//` rounds down.
3. **Common-mistakes gaps, with real messages** (5, 9, 21, 29): wrong folder (how to see it), `>>>` prompt, unsaved file, `$80`/`15%`, `if age = 5:`, forgotten colon.
4. **Exercise logistics and consistency** (7, 16, 20): say where to copy a starter and how to run it; unzip instructions; make the `split_bill` starter match what the steps taught and the Best practice.
5. **Undefined terms** (27, 30, 17, 11, 12, 24): define boolean expression, condition, block, `elif`, concatenate, `TODO`, `sudo/apt`, and ship or link the glossary.
