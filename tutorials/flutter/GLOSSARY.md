# Flutter glossary

## 101
- **Flutter / Dart**: the UI toolkit and its language. **SDK**: bundle of tools. **widget**: one building block of the screen. **emulator**: pretend phone. **PATH**: folders searched for commands.
- **hot reload / hot restart**: update the running app with changed code (`r`), or restart it (`R`).
- **variable, type, final, const, null safety, `String?`, `??`, `?.`**: Dart basics (lesson 02). **function, named and optional parameter**.
- **List, Map, Set, class, constructor, enum, closure, Future, async, await, try/catch**: lesson 03.
- **widget tree, Column, Row, Padding, SizedBox, Expanded, Card, Container, constraints**: layout (lesson 04).
- **StatelessWidget, StatefulWidget, State, setState**: lesson 05. **controller, Form, validator, ListView.builder, Dismissible, immutable, copyWith**: lesson 06.
- **Navigator, route, back stack, pop result**: lesson 07. **ThemeData, ColorScheme, seed colour, asset, SVG**: lesson 08.
- **HTTP, status code, JSON, model, factory constructor, timeout**: lesson 09. **persistence, key-value storage, `mounted`**: lesson 10.
- **semantics, TalkBack, tooltip, touch target, text scale, LayoutBuilder, adaptive layout**: lesson 11.
